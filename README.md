# Stencil
Extract design patterns from your web browser usage, elevating repetitive telemetry into autonomous behavior.

Traditional automation maps the *how*; Stencil maps the *why*. By processing your browser session, it reverse-engineers the actual decision tree of your task. It observes the environment, extracts the core navigational pattern, and deploys an agent equipped with the exact cognitive framework needed to execute the workflow on its own.

### The Real-Time Handoff
The core use case isn't just post-session scripting—it's live, runtime abstraction. You initiate a manual, repetitive task in your browser. Stencil watches the active state, deduces your semantic intent on the fly, and seamlessly takes the wheel to finish the execution or assist you through complex workflows. 

You execute the first loop. The agent grinds the rest.
